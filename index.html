Cài đặt ExpenseFlow App

1

Trên trình duyệt Safari (iPhone/iPad), bấm vào nút Chia sẻ (Share) ở thanh dưới cùng.

2

Cuộn xuống và chọn "Thêm vào MH chính" (Add to Home Screen) .

3

Bấm Thêm (Add) ở góc trên bên phải. Ứng dụng sẽ xuất hiện trên màn hình chính như một App tải từ App Store!

Cấu hình Firebase cho dự án của bạn

Để lưu trữ và đồng bộ hóa qua Gmail của bạn, chỉ cần 3 bước đơn giản:

  1. Truy cập Firebase Console và bấm Add project.
  2. Vào mục Authentication > Tab Sign-in method > Chọn và bật Google.
  3. Vào Firestore Database > Tạo database và cập nhật Security Rules: 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/expenses/{expenseId} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
  4. Tại Project Overview > Bấm vào biểu tượng </> để lấy firebaseConfig rồi dán vào file app.js.

Chi tiết tường tận từ A-Z hãy xem tại file README.md!
